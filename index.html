StaffSheet Quick Setup

Google Sheetsの名簿を使って、スタッフごとの移動先や表示Objectを設定します。上から順に進めれば、初回設定が完了します。

初めての方向け目安 10〜15分Tag / CSV Exporterは任意

このガイドでできること

Google Sheetsの共有設定から、Unity Sceneへの反映までを設定します。GroupごとにTeleport PointやObjectのON/OFFを割り当てられます。

始める前に

  • VRChat Worlds SDKとUdonSharpを導入したUnityプロジェクト
  • VRChat DisplayNameを記載したGoogle Spreadsheet
  • 設定するSceneを開いたUnity Editor
1

Google Sheets

名簿をGroupごとに作る

1行目にGroup名、2行目以降にスタッフのVRChat DisplayNameを入力します。

1セルに1つの名前を入力してください。列を増やすとGroupを追加できます。名前はVRChatのDisplayNameと同じ表記にします。大文字・小文字も区別されます。

2

Google Sheets

閲覧リンクを共有する

SheetStaffが名簿を取得できるよう、共有範囲と権限を設定します。

共有ダイアログでリンクをコピーします。このURLを次のStepでUnityへ入力します。

注意　「ウェブに公開」のCSV URLではなく、Google Sheetsの共有URLを使ってください。リンクを知る人は名簿を閲覧できます。また、VRChat DisplayNameは本人が変更できるため、SheetStaffを秘密情報や重要操作を守る認証として使わないでください。
3

Unity · 初回のみ

利用規約に同意し、Managerを用意する

SheetStaffの設定Windowを開き、SceneにManagerを1つ作成します。

  1. Unityのメニューから Tools > ARTS > SheetStaff を開きます。
  2. SceneにManagerがなければ「Managerを作成」を押します。通常はSceneごとに1つだけ配置します。

すでにManagerがあるSceneでは「現在のSceneからManagerを取得」を選びます。

4

Unity · Sheet

共有URLを入力してSheetを読み込む

SheetタブでURLを読み込み、Group一覧をUnityへ取り込みます。

取得開始方式は、まず既定の「自動」のままで進められます。別タブを使う場合などを除き、Advancedのgidは変更不要です。

注意　取得にはVRChatクライアント側で Allow Untrusted URLs が許可されている必要があります。Googleの共有設定も確認してください。
5

Unity · Groups

Groupごとの動作を設定する

名簿のGroupを選び、必要なTeleportとObject Actionsを登録します。

  1. 左側で設定するGroupを選びます。画面は選択中のGroupだけを編集します。
  2. スタッフに見せたいObjectは「＋ ON Objectを追加」、隠したいObjectは「＋ OFF Objectを追加」を押します。
  3. 追加行のObject欄へHierarchyから対象GameObjectをドラッグするか、丸い選択ボタンから指定します。「ONにする / OFFにする」が意図した状態か確認します。
  4. Teleportを使う場合は「このGroupのTeleportを使用する」をONにし、Teleport Pointへ移動先のTransformを指定します。
  5. 他のGroupも選び、必要なObjectとTeleportを設定します。
例　スタッフだけに見せたいパネルは、Scene開始時にOFFにしてから、該当GroupへON Objectとして登録します。GuestはScene開始時の状態に戻ります。
注意　同じObjectを複数Groupで異なる状態に設定した場合、Sheetで左側にあるGroupの設定が優先されます。意図しない競合を避けるため、登録先を確認してください。
6

任意 · Role Tag

スタッフの頭上Tagを設定する

頭上にRole表示を出したい場合だけ設定します。通常のSheetStaff判定には必須ではありません。

  1. Role / TagタブでRole TagをONにし、必要に応じてGroupごとのRole名を編集します。
  2. Step 7でApplyすると、Tag用のPlayerObjectや標準表示が自動設定されます。
  3. 必要ならTag DesignでText / Image、表示文字や画像、高さなどを調整します。
注意　Role Tagの切替やRole名の編集だけではSceneへ反映されません。必ず最後にApplyしてください。
7

Apply · Save

設定をSceneへ反映して保存する

最後に設定を適用し、Sceneファイルを保存します。

  1. Footerの検証結果を確認します。Errorがあれば解消します。
  2. 「Apply」を押し、Hierarchy / Sceneへ設定を反映します。
  3. Unityの File > Save（または Ctrl+S）でSceneを保存します。
大切　ApplyとScene保存は別の操作です。Apply後にSceneを保存してください。ワールドへ反映するには、その後VRChat SDKでBuild / Uploadします。

スタッフ認証ボタン

取得開始方式をスタッフ認証にした場合、Sheetタブの「Applyして認証ボタンを生成 / 更新 / 選択」を押します。既存ボタンは配置とデザインを保ち、不足する状態表示だけ追加します。更新後はSceneを保存してください。

ボタンには確認中・Staff確認済み・所属なし・取得失敗が表示されます。Export通信中に押した認証要求は保留され、本人の通常取得で判定します。連打する必要はありません。表示文言はInspectorで変更でき、日本語には対応TMP Fontが必要です。VRChat内で位置・文字・押しやすさを確認してください。

任意：Staff専用 CSV Exporter

表示されないとき　Sceneビュー右上の球体のような「Gizmos」表示をONにしてください。ここで表示される枠はEditor上の確認用です。VRChat内の操作パネルそのものではありません。

入室・退出を別行で出力します。列はEventDate / EventTime / DisplayName / Event（JoinまたはLeave）。上限は入退室合計512件です。既存の3列シートには4列目を追加してください。Owner交代中の未観測イベントは推測しません。

  1. SheetStaff WindowのCSV Exporterタブで「作成（Create）」を押し、Target Managerを確認します。旧配置は「参照修復（Repair）」で形式・ヘッダー切替を追加します。既存Targetは自動変更されません。
  2. Exporter本体・JoinRecordStoreは有効のままにします。操作Canvasだけが、本人の通常取得でStaffと確認された後に表示されます。認証モードでは先にスタッフ認証してください。
  3. Googleスプレッドシートへの貼り付けには標準のTSVを推奨します。Formatで互換用CSVにも切替可能です。Include Headerは既定OFF、新しいシートにはONにできます。Generate / Retryで最新Staffを再取得して除外し、出力欄でVRChat標準入力のSelect All / Copyを使ってセルへ貼り付けます。形式変更後は再生成してください。
  4. InspectorのExport Utc Offset Hoursは既定+9（−12〜+14）。記録・同期はUTC、CSV／TSV出力だけ固定オフセットを適用します。最後にSceneを保存してBuildします。

GuestのJoinも記録しますが操作UIは表示しません。通常取得失敗・資格喪失時はCSVを破棄します。上限512件、インスタンス終了で消去、Persistence未使用。同期履歴の完全な秘匿は保証できません。定期取得OFFでは本人の通常取得を手動実行してください。PC・VR・Questのコピー操作・描画・同期は実機確認が必要です。

✓

セットアップ完了

SheetStaffの基本設定がSceneに保存されました。VRChat SDKでBuild & Testを行い、URL取得やGroup別の動作を確認してください。

うまく読み込めないとき

Sheet読込に失敗する
共有URLを貼り直し、「リンクを知っている全員」が閲覧できる設定か確認します。「ウェブに公開」のURLは使用しません。
VRChat内で取得できない
利用者のVRChat設定で Allow Untrusted URLs が有効か確認します。
Applyできない
FooterのErrorを開き、案内されたGroup設定などを修正してから再度Applyします。
変更がSceneに残らない
Applyの後にSceneを保存したか確認します。Windowを閉じるだけではSceneファイルは保存されません。
